# Campaign Crafter Web

Crie o MVP de um sistema web chamado Disparador WhatsApp, usando React, TypeScript, Tailwind CSS e shadcn/ui, em português do Brasil. Utilize um visual SaaS profissional, com azul-marinho (#0B1F3A), azul (#13315C), destaque (#1E5AA8) e fundo claro (#F4F7FB).

Desenvolva somente estas funcionalidades:

Login e Registro: formulários simples e navegação entre as telas.

Dashboard: resumo de campanhas e métricas com dados fictícios.

Criar Campanha: formulário para definir o nome, selecionar grupos de contatos do HubSpot, escolher um template de mensagem com variáveis como {{nome}}, visualizar a mensagem e revisar os dados da campanha.

Grupos de Contatos: listar grupos fictícios do HubSpot, permitir pesquisar e selecionar contatos e criar grupos a partir dos contatos selecionados.

Inclua uma sidebar simples com Dashboard, Campanhas, Criar Campanha e Grupos de Contatos. A opção Campanhas pode exibir apenas uma listagem básica das campanhas.

Restrições importantes:

Use dados mockados e organize os serviços para futuras integrações com HubSpot, n8n e Z-API.

Não implemente integrações reais, disparos reais de WhatsApp, automações, configurações avançadas ou funcionalidades futuras.

Não crie páginas, componentes ou recursos além dos solicitados.

Priorize uma interface funcional, simples e consistente, sem complexidade desnecessária.

Não instale dependências extras sem necessidade.
